# Public Repository Content Policy

This repository is intentionally compact and research-facing.

## Included publicly

- source code required to understand and reproduce the AURA-CXR workflow;
- frozen configuration files and random seeds;
- exact patient-level split derivatives for the public RSNA dataset;
- compact paper-facing numerical summaries;
- environment/dependency files, citation metadata, and technical documentation.

## Intentionally excluded

- manuscript drafts and journal-production files;
- internal working notes, quality-control traces, temporary artifacts, and local logs;
- raw medical images;
- pretrained or derived checkpoint binaries whose redistribution rights are not established;
- redundant per-case prediction exports and large intermediate analysis outputs;
- cache files, private paths, and machine-specific runtime artifacts.

The public repository is therefore focused on implementation, scientific reproducibility, and citation rather than the authors' internal working archive.
