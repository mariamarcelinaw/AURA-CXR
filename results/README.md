# Released result summaries

This directory intentionally contains only compact, paper-facing numerical summaries.
It does **not** contain raw medical images, private/local experiment logs, internal editorial correspondence,
manuscript drafts, or the full set of per-case/intermediate outputs used during internal quality control.

- `reported_metrics.json` — compact reported metrics for the frozen AURA-CXR configuration.
- `golden_reference.json` — integrity reference used by verification utilities.

For exact experimental procedures, use the code, frozen configurations, and split files in this repository.
